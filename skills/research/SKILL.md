---
name: research
description: Investigate a question against high-trust primary sources and capture the findings as a Markdown file in the repo. Use when research should persist as notes in the repo or be delegated to a background agent.
---

1. Define the question, its scope, and any required version or date. Inspect the repository's research-note convention and choose a non-conflicting output path.
2. Delegate to an available background agent when independent reading lets the caller continue useful work. Pass the question, constraints, output path, and evidence requirements below. Otherwise, research synchronously. A delegated researcher owns its assignment and only delegates further when independent subtasks justify it.
3. Investigate against primary sources: official documentation, source code, specifications, and first-party APIs. For repository claims, cite exact paths and lines. For external claims, cite direct URLs and relevant versions or dates. Distinguish source findings from inference.
4. Save one Markdown note containing the answer, supporting evidence, contradictions, and unresolved questions. Use the repository's existing location; when none exists, choose a descriptive path under `notes/`.
5. Read the saved note before delivery. A delegated task is complete only after its result is received and checked. Every requested question must have an evidence-backed answer or an explicit unresolved status. Return the absolute path and material limitations.
